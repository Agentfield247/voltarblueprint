Voltar internal spec · corrected

Product, team, rules, money, screens

Heart-care app + Voltar X watch. Chat-first. AI is a companion, not a doctor. Doctors prescribe. Pharmacy sources drugs. Guests can pay as they go.

Team Rules AI Money Home Shop Consult Watch

Important!

AI never diagnoses “what’s wrong” and never prescribes. If the user needs that, route to a licensed clinician.
Shop does not show stock counts. It checks availability with vendors.
Users do not browse a doctor marketplace. Voltar assigns a clinician after intake.
Recordings and prescription images are sensitive health data — consent + lock-down required.

2. Other rules we need

Product

  • Service before signup. Open app → chat is already there. Account only when they pay for drugs, save history, or subscribe.
  • Guest is first-class. “Quick Consultation” works anonymous until checkout / Rx fulfillment needs a name.
  • Chat is the OS. Home is not a dashboard of 20 tiles. Chat + call + sign-in.
  • Voltar answers product questions too (“how do I book video?”) and can route.
  • Watch versions are named Voltar X Series N (Series 1, Series 2…).

Clinical safety

AI must not: name a disease as the cause, suggest a drug, dose, or “you probably have X”.
AI may: ask how they feel, listen, summarize for a doctor, calm them, explain how Voltar works, and hand off to a human.
  • Prescription-only medicines: blocked in shop until a Voltar doctor issues an Rx.
  • Emergency language (“chest pain”, “can’t breathe”, suicidal talk) → show emergency actions + optional auto-call path. Do not chat it away.
  • Doctors prescribe. Pharmacy sources. Voltar does not invent stock.

Legal / ops (must budget)

  • Telemedicine rules in each country we launch (Nigeria first: licensed clinicians, informed consent).
  • Pharmacy partnership / no illegal retail of controlled drugs.
  • Data protection (NDPR and similar). Health records encrypted. Need-to-know access.
  • Call/video/photo recording: explicit consent, retention limit, admin-only playback.
  • Age gate. Minors need a guardian flow later — do not launch that sloppy.
  • Insurance/HMO is phase 2. Do not claim “we issue insurance” until licensed.
  • Watch BP cuff is a medical-device path. App can ship without the watch.

Matching doctors

  • No doctor shopping grid on the consult page.
  • AI + rules pick one clinician from specialty, language, load, and reputation.
  • Reputation score is visible after that patient has finished a session with that doctor (or in history). Both sides leave a review.
  • Switching doctors is a support / reassign action, not a swipe deck.

3. AI layer (helper, not the product)

Use existing models (Grok, ChatGPT, etc.). The model is a fast, kind layer. Humans do medicine.

Allowed

  • Open with “How are you feeling today?”
  • Ask about their day, sleep, mood, watch readings if linked.
  • Collect symptoms into a structured intake the doctor can read.
  • Explain Voltar (plans, how consults work, how pharmacy works).
  • Recommend that they see a specialist, then create a session.
  • Trigger emergency UI / call if they sound in danger.
  • Voice check-in via ElevenLabs (automated). Same guardrails as text.

Forbidden

  • Prescribe or name doses.
  • Give a probable diagnosis or “this is likely X”.
  • Argue the user out of seeing a doctor when risk is high.
  • Unmonitored long-running advice. Logs reviewed. Jailbreaks blocked.

Prompt stack: system policy → intake schema → handoff card for the doctor → never a treatment plan.

Consult channel prices (relative)

  • Chat — cheapest
  • Voice — more
  • Video — more
  • Physical visit — booked from the doctor’s free slots
  • Full pack — chat + voice + video (and physical if added)

Users pick the mode before the session starts. Mid-session they can migrate (chat → video → chat) if they pay the difference. Time remaining carries when possible.

Why guest checkout exists: TikTok / YouTube pattern. Use first, account when they need memory, delivery, or a watch.

5. Home = chat

  • Full-screen thread. First line already waiting: “How are you feeling today?”
  • Call button = automated ElevenLabs check-in (not a random human on first tap).
  • Sign in sits in the corner. Not a wall before chat.
  • If watch is linked: tiny BP / HR chip in the header, tap to expand. Not a second home.
  • Ask Voltar anything about the app; it routes (“open pharmacy”, “start consult”).

6. Shop / pharmacy / cart

  • Search drugs. Each card: name, what it is used for, Rx required or not.
  • No “40 in stock”. User selects → we ask availability (vendor / partner pharmacy) → reply yes/no + ETA + price.
  • They can ask availability without paying.
  • OTC can check out as guest. Rx-only: doctor session first, then cart becomes a “consult kit”.
  • Upload prescription: AI reads the image, matches catalogue SKUs, then the same availability flow. If a line is missing, still ask vendors. A pharmacist/clinician must confirm before dispense when the law requires it.
  • Pay for drugs → prompt signup so delivery and history have a name.
  • If we cannot source it, user may pick up at a nearby partner pharmacy with the e-Rx.

7. Consult & chat

One thread. AI gathers what a doctor needs. System picks a clinician. Session starts. No profile mall.

Session object

  • Duration — paid timeframe
  • Migrations — chat ↔ voice ↔ video (and later physical)
  • Media — photos, voice, video. Private. Voltar admins + treating clinician only. Stored encrypted.
  • Prescriptions — doctor writes Rx → user checks out as a kit → we source & deliver or send to nearby pharmacy
  • Schedule — upcoming / can book another day / can cancel
  • History — past sessions, ratings (after the visit)

After the session

  • Patient rates doctor. Doctor rates encounter quality (no public attack thread).
  • Only then does that patient see that doctor’s reputation and other reviews.

Settings / records

Meds, allergies, conditions, watch trends. Stored so the assigned doctor does not start from zero.

8. Platforms & Voltar X

  • Now: Flutter app on phone. Laptop/desktop for video + chat + booking.
  • Watch: Voltar X Series 1, Series 2… cuff strap BP, HR, ECG, steps, sleep, med alarms, daily BP push to the assigned clinician on subscription plans.
  • Hardware follows the existing watch prototype + blueprints. App can launch without Series 1 in hand.

9. Core user flows (short)

  1. Open app → AI chat (guest).
  2. Feels unwell → intake → pay wall for human consult (shown up front) → assigned doctor.
  3. Doctor Rx → availability check → pay → signup if still guest → deliver or pharmacy pickup.
  4. Looks fine → shop OTC → availability → pay → signup prompt.
  5. Subscriber → watch auto-syncs → daily BP → clinician sees flags, not a 24/7 raw dump.
  6. Emergency phrase → emergency actions, stop casual chat.
